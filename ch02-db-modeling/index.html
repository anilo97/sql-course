[서비스 시나리오] AI 홈 재활 운동 관리 플랫폼

가정에서 재활 운동을 수행하는 환자의 상태를 체계적으로 관리하기 위해 아래 3가지 핵심 업무를 처리해야 합니다.

  • ① 업무 1 : 환자 등록
  • ② 업무 2 : 재활 운동 처방
  • ③ 업무 3 : 운동 수행 기록 측정
작성 팁: 업무 문장은 ~을(를) ~한다 형식을 기본으로 쓰되, 주체가 필요한 경우 누가 무엇을 어떻게 한다처럼 작성해도 좋습니다. 세부 항목(열)은 다음 단계에서 정하므로 여기서는 큰 덩어리 이름(표 제목)만 뽑아냅니다.
구분 업무 문장 (동사형 작성) 핵심 명사 (한글 테이블명) 영문 테이블명 (Physical Name)

STEP 04

MySQL Workbench EER 다이어그램 구축

이번 단계에서 반드시 할 일: 논리 설계 표를 MySQL 물리 데이터 타입으로 변환하여 Workbench EER 다이어그램에 테이블 3개와 1:N 관계선(FK)을 구축하세요.

1. 논리 형식 → MySQL 물리 데이터 타입 변환 기준

논리 형식 MySQL 물리 타입 적용 예시 실무 선택 기준
문자 VARCHAR(길이)
CHAR(길이)		 patient_id VARCHAR(20)
gender CHAR(1)		 길이가 변하면 VARCHAR, M/F처럼 고정 길이는 CHAR
숫자 INT
FLOAT / DECIMAL		 log_id INT, pain_score INT
avg_rom FLOAT		 정수·자동 증가 번호는 INT, 소수점 측정값은 FLOAT
날짜 DATE
DATETIME		 birth_date DATE
performed_at DATETIME		 연-월-일만 저장하면 DATE, 시:분:초까지 기록하면 DATETIME
MySQL Workbench 입력 시 자주 발생하는 데이터 타입 에러 주의사항
  • DATETIME() · TIME() 빈 괄호 에러: 드롭다운 메뉴에서 DATETIME()을 선택하면 빈 괄호 때문에 "Could not set new data type" 에러 팝업이 뜹니다. 반드시 괄호를 지우고 DATETIME만 입력하거나 키보드로 직접 타이핑하세요.
  • VARCHAR 길이 누락 에러: VARCHAR는 반드시 괄호 안에 최대 글자 수를 적어야 합니다. 길이 없이 VARCHAR만 입력하면 적용되지 않으므로 VARCHAR(20)처럼 숫자를 지정하세요.
  • CHAR 길이 초과 주의: CHAR(1)로 지정한 열에 '남성'(2글자)을 넣으면 길이가 초과됩니다. 한글 1~2글자 데이터를 저장할 계획이라면 넉넉하게 VARCHAR(10)을 사용하세요.
  • INT와 AI(Auto Increment) 제약: 자동 증가(AI) 체크박스는 데이터 타입이 정수(INT)이고 기본 키(PK)로 지정된 열에만 사용할 수 있습니다. 문자형(VARCHAR)에는 AI를 체크할 수 없습니다.
  • 외래 키(FK) 데이터 타입 일치 필수: 1:N 관계선으로 연결되는 부모 테이블의 PK와 자식 테이블의 FK는 데이터 타입과 길이가 완전히 같아야 합니다. (점선 1:n 도구를 쓰면 Workbench가 자동으로 동일 타입을 맞춰줍니다.)
