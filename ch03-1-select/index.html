SELECT ~ FROM ~ WHERE 실전 조회 미션

MySQL Workbench에서 USE market_db;를 먼저 실행한 뒤, 아래 7단계 요구사항에 맞는 SQL 조회 쿼리를 직접 작성해 실행해 보세요. 결과 확인 후 내가 작성한 쿼리를 아래 입력란에 기록하고 완료 체크를 진행합니다.
[참고] market_db 테이블 및 열(Column) 구조
회원 테이블 (member): mem_id(아이디), mem_name(이름), mem_weight(몸무게), addr(주소), phone1(국번), phone2(전화번호), height(키), debut_date(생년월일/가입일)
구매 테이블 (buy): num(순번), mem_id(회원 아이디), prod_name(물품명), group_name(분류), price(단가), amount(수량)
